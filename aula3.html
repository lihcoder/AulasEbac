🎛️ Simule Diferentes Tamanhos de Tela

🎯 Exemplo 1: Imagem Hero (Largura Total)

A imagem ocupa 100% da largura da tela em todos os dispositivos

</> Código HTML

<img
  src="hero-fallback.jpg"
  
  srcset="
    hero-small.jpg 600w,
    hero-medium.jpg 1200w,
    hero-large.jpg 1800w,
    hero-xlarge.jpg 2400w"
  
  sizes="100vw"
  
  alt="Paisagem montanhosa"
>

<!-- sizes="100vw" significa:
     A imagem sempre ocupa 
     100% da largura da viewport -->

🛍️ Exemplo 2: Grid de Produtos (Responsivo)

Mobile: 1 coluna (100%) | Tablet: 2 colunas (50%) | Desktop: 3 colunas (33%)

</> Código HTML

<img
  src="produto.jpg"
  
  srcset="
    produto-300.jpg 300w,
    produto-600.jpg 600w,
    produto-900.jpg 900w,
    produto-1200.jpg 1200w"
  
  sizes="
    (max-width: 640px) 100vw,
    (max-width: 1024px) 50vw,
    33vw"
  
  alt="Produto"
>

<!-- Lógica do sizes:
     📱 Tela até 640px: ocupa 100%
     💻 Tela até 1024px: ocupa 50%
     🖥️ Tela maior: ocupa 33% -->

📌 Exemplo 3: Thumbnail de Sidebar (Tamanho Fixo)

A imagem sempre tem 250px de largura, independente da tela

</> Código HTML

<img
  src="thumb.jpg"
  
  srcset="
    thumb-250.jpg 250w,
    thumb-500.jpg 500w"
  
  sizes="250px"
  
  alt="Miniatura"
  style="max-width: 250px;"
>

<!-- sizes="250px" significa:
     A imagem sempre ocupa 250px
     
     Útil para sidebars,
     avatares e thumbnails -->

✨ Exemplo 4: Imagens para Telas Retina (Density Descriptors)

Usa "x" em vez de "w" para especificar a densidade de pixels

</> Código HTML

<img
  src="logo.png"
  
  srcset="
    logo.png 1x,
    logo@2x.png 2x,
    logo@3x.png 3x"
  
  alt="Logo"
  style="width: 200px;"
>

<!-- Density Descriptors:
     1x = telas normais
     2x = telas Retina (iPhone, MacBook)
     3x = telas de alta densidade
     
     Não precisa de sizes! -->
